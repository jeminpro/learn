# Vocab bank

### Core PE and Movement

| Word                        | Meaning                                                                     |
| --------------------------- | --------------------------------------------------------------------------- |
| **Physical education (PE)** | Learning about physical activity, movement, exercise and sport.             |
| **Exercise**                | Physical activity done to improve or maintain fitness and health.           |
| **Movement**                | The act of changing the position of the body or a body part.                |
| **Locomotion**              | Movement from one place to another.                                         |
| **Speed**                   | How quickly something moves.                                                |
| **Distance**                | How far something travels or how far apart two things are.                  |
| **Direction**               | The way in which someone or something moves.                                |
| **Space**                   | The area available for movement.                                            |
| **Pathway**                 | The route followed when moving.                                             |
| **Level**                   | The height at which a movement takes place, such as low, medium or high.    |
| **Sequence**                | A series of movements performed in a particular order.                      |
| **Routine**                 | A planned sequence of movements or skills.                                  |
| **Balance**                 | The ability to keep the body steady without falling.                        |
| **Coordination**            | The ability to make different parts of the body work together effectively.  |
| **Control**                 | The ability to manage body movements or equipment successfully.             |
| **Agility**                 | The ability to move quickly and easily, especially when changing direction. |
| **Timing**                  | Performing a movement at the correct moment.                                |
| **Rhythm**                  | A regular pattern or beat of movement.                                      |

### Fitness

| Word              | Meaning                                                                            |
| ----------------- | ---------------------------------------------------------------------------------- |
| **Fitness**       | The ability of the body to cope with physical activity effectively.                |
| **Strength**      | The ability of muscles to produce force.                                           |
| **Flexibility**   | The ability to move joints and muscles through a wide range of movement.           |
| **Stamina**       | The ability to continue physical activity without becoming too tired.              |
| **Endurance**     | The ability to keep exercising or performing for a long period.                    |
| **Power**         | The ability to use force quickly.                                                  |
| **Speed**         | The ability to move quickly.                                                       |
| **Heart rate**    | The number of times the heart beats in one minute.                                 |
| **Pulse**         | The beat that can be felt in an artery as the heart pumps blood.                   |
| **Warm-up**       | Gentle exercise done before harder activity to prepare the body.                   |
| **Cool-down**     | Gentle activity done after exercise to help the body return to its resting state.  |
| **Recovery**      | The process of the body returning towards its normal resting state after exercise. |
| **Fatigue**       | Extreme tiredness, especially after physical activity.                             |
| **Personal best** | The best performance or result an individual has achieved.                         |

### Skills and Performance

| Word            | Meaning                                                        |
| --------------- | -------------------------------------------------------------- |
| **Skill**       | An ability that has been learned and practised.                |
| **Technique**   | The particular way of performing a skill.                      |
| **Performance** | How well someone performs an activity or skill.                |
| **Accuracy**    | How close a result is to the intended target.                  |
| **Practise**    | To perform a skill repeatedly in order to improve it.          |
| **Evaluate**    | To judge how successful something has been.                    |
| **Feedback**    | Information about a performance that can help someone improve. |
| **Strengths**   | Things that someone performs particularly well.                |
| **Weaknesses**  | Areas where someone needs to improve.                          |
| **Consistency** | The ability to perform a skill successfully again and again.   |

### Running, Jumping, Throwing and Catching

| Word           | Meaning                                                          |
| -------------- | ---------------------------------------------------------------- |
| **Sprint**     | Run as fast as possible over a short distance.                   |
| **Stride**     | A long step or the length of a step when running.                |
| **Accelerate** | To increase speed.                                               |
| **Decelerate** | To reduce speed.                                                 |
| **Skip**       | Move by stepping and hopping alternately.                        |
| **Dodge**      | Quickly move out of the way of something or someone.             |
| **Throw**      | Send an object through the air using the hand or arm.            |
| **Catch**      | Stop and control a moving object, usually with the hands.        |
| **Receive**    | Successfully take control of a ball or object sent to you.       |
| **Pass**       | Send a ball or object to another player.                         |
| **Strike**     | Hit an object with a hand, foot, bat, racket or other equipment. |
| **Kick**       | Strike a ball with the foot.                                     |
| **Roll**       | Send an object along the ground.                                 |
| **Dribble**    | Move while repeatedly controlling a ball.                        |

### Games, Attack and Defence

These are particularly important because the KS2 curriculum specifically requires pupils to apply basic principles of **attacking and defending** in competitive games. ([GOV.UK][1])

| Word                | Meaning                                                                 |
| ------------------- | ----------------------------------------------------------------------- |
| **Competition**     | An activity in which people or teams try to achieve the best result.    |
| **Opponent**        | The person or team you are competing against.                           |
| **Teamwork**        | Players working together effectively towards a common goal.             |
| **Cooperation**     | Working together to achieve something.                                  |
| **Attack**          | An attempt to score or gain an advantage over an opponent.              |
| **Defend**          | An attempt to stop an opponent from scoring or gaining an advantage.    |
| **Attacker**        | A player whose role is mainly to try to score.                          |
| **Defender**        | A player whose role is mainly to prevent the opposition from scoring.   |
| **Possession**      | Having control of the ball.                                             |
| **Tactic**          | A plan or action used during a game to gain an advantage.               |
| **Strategy**        | A broader plan for achieving a goal.                                    |
| **Position**        | Where a player stands or moves during a game.                           |
| **Space**           | An open area that can be used by a player or team.                      |
| **Support**         | Moving into a useful position to help a teammate.                       |
| **Mark**            | Stay close to an opposing player to limit their options.                |
| **Intercept**       | Stop and take control of a pass intended for another player.            |
| **Fair play**       | Following the rules and treating other players fairly and respectfully. |
| **Match**           | A contest between individuals or teams.                                 |
| **Draw**            | A competition in which the sides finish with the same score.            |
| **Pitch**           | The playing area used for sports such as football and hockey.           |
| **Equipment**            | Objects and items used to take part in a sport or activity.                     |
| **Racket**               | Equipment with a handle and striking surface used to hit a ball or shuttlecock. |

### Athletics, Gymnastics

| Word              | Meaning                                                                 |
| ----------------- | ----------------------------------------------------------------------- |
| **Athletics**     | A group of sports involving running, jumping and throwing.              |
| **Relay**         | A race in which members of a team run different sections of the course. |
| **Baton**         | The object passed between runners in a relay race.                      |
| **Hurdle**        | An obstacle that runners jump over.                                     |
| **Long jump**     | An event in which an athlete tries to jump as far as possible.          |
| **High jump**     | An event in which an athlete tries to jump over a raised bar.           |
| **Pace**          | The speed at which someone performs an activity, especially running.    |
| **Gymnastics**    | Physical activity involving controlled movements, balance, strength and flexibility. |
| **Posture**       | The way the body is held or positioned.                                              |
| **Muscle**         | Body tissue that contracts to produce movement.                                             |
| **Stretch**        | To lengthen a muscle through movement or a controlled position.                             |

### Dance

| Word                 | Meaning                                                             |
| -------------------- | ------------------------------------------------------------------- |
| **Choreography**     | The planning and arrangement of dance movements.                    |
| **Expression**       | Using movement to communicate feelings or ideas.                    |
| **Formation**        | The arrangement of dancers in relation to one another.              |

### Swimming and Water Safety

| Word             | Meaning                                                                                   |
| ---------------- | ----------------------------------------------------------------------------------------- |
| **Swimming**     | Moving through water using the body and limbs.                                            |
| **Stroke**       | A particular method of moving through water.                                              |
| **Front crawl**  | A swimming stroke performed face-down using alternating arm movements and a flutter kick. |
| **Backstroke**   | A swimming stroke performed on the back using alternating arm movements.                  |
| **Breaststroke** | A swimming stroke using simultaneous arm movements and a frog-like leg kick.              |
| **Float**        | Remain on the surface of the water without sinking.                                       |
| **Propel**       | Push or drive yourself forward.                                                           |
| **Water safety** | Knowing how to behave safely in and around water.                                         |
| **Buoyancy**     | The ability of something to float or be supported by water.                               |

### Outdoor and Adventurous Activities

| Word                | Meaning                                                                                  |
| ------------------- | ---------------------------------------------------------------------------------------- |
| **Challenge**       | A task that requires effort, skill or problem-solving.                                   |
| **Adventure**       | An activity involving exploration, challenge or unfamiliar situations.                   |
| **Navigation**      | Finding and following a route from one place to another.                                 |
| **Route**           | The path or course followed to reach a destination.                                      |
| **Map**             | A drawing that represents an area and helps people find their way.                       |
| **Compass**         | An instrument used to find direction.                                                    |
| **Orienteering**    | An activity involving navigation between marked points, usually using a map and compass. |
